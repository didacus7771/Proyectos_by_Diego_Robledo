1. QUÉ ES ESTO
------------------------------------------------------------------
Es un BORRADOR del dashboard del proyecto de pronóstico de inflación mensual argentina
(IPC INDEC), escrito como proyecto de Power BI (.pbip: archivos de texto) en
dashboard/pbip/. Claude Code no pudo abrir Power BI Desktop: la estructura se
verificó solo con scripts (JSON válido, referencias cruzadas y esquemas oficiales de
Microsoft). Nadie vio todavía el resultado en pantalla. Lo abres tú, lo revisas y
corriges lo visual.

Contiene: modelo semántico en formato TMDL con 3 tablas nuevas (dim_horizonte,
dim_regimen y Medidas), 11 relaciones nuevas y 26 medidas; informe en formato PBIR con
4 páginas de 1280 x 720. Las 7 tablas y sus consultas a PostgreSQL son las que dejaste
tú en dashboard/pbip_base/ (no se tocaron). Las tablas conservan el prefijo "inflacion "
(por ejemplo 'inflacion vw_evaluacion'), tal como las nombró Power BI.

1.1 Cómo abrirlo
  1. Abre dashboard/pbip/inflation_forecast.pbip con Power BI Desktop. Si pide habilitar
     algo (por ejemplo la vista previa de proyectos), acéptalo.
  2. Pulsa Actualizar y escribe las credenciales de PostgreSQL (servidor localhost:5433,
     base inflacion_arg; usuario y contraseña de tu .env). La caché de datos no se incluyó.
     El contenedor de Docker tiene que estar encendido.
  3. Comprueba que las 7 tablas cargan sin error y que aparecen las tablas dim_horizonte,
     dim_regimen y Medidas.
  4. Compara las medidas con los valores de control de la sección 3.
  5. Corrige lo visual y guarda como dashboard/inflation_forecast.pbix.
  6. Exporta el PDF y las capturas (una por página).
  Si Desktop no abre el proyecto o muestra un error, copia el mensaje exacto: es la
  información que necesito para corregirlo.

  - Las medidas con IF(HASONEVALUE(...)) devuelven vacío si no hay un solo horizonte
